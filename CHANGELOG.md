# Changelog

## v1.0.0

First release of the Worship Team phone app.

- Home for guests, members, song leaders and the admin: this Sunday, your part, songs and the team
- "I'll be there" / "Can't serve" with a cover, and the absence rule
- Songs: view with Listen and Chords links; the leader of that Sunday can edit them
- Schedule by month, Sunday details, admin swap / mark absent / remove a spot / add someone
- Auto-shuffle for a month, with team size per role set by the admin (e.g. 2 guitars)
- "Who came?": only members who confirmed get +10
- Points ranking, admin add/remove points, recent changes
- Team directory: add, edit, import, copy logins, reset
- Weekly reminders on the phone with Yes / Can't serve buttons
- Sign in as an overlay, live updates between phones, works offline from the last saved data
- Church logo app icon, smooth animations
